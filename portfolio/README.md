# 🚀 Animated Developer Portfolio

A modern, highly interactive personal portfolio built to showcase full-stack MERN and Machine Learning projects. Engineered with React and Vite, featuring complex scroll-triggered animations via GSAP and a fluid physics-based custom cursor.

## ✨ Key Features
- **GSAP Animations:** Advanced scroll-triggered reveals, staggered grids, and a custom gooey physics-based cursor.
- **Dynamic Project Fetching:** Automatically pulls live repository data directly from the GitHub API.
- **Dark Mode Toggle:** Seamless transition between light and dark themes with local storage persistence.
- **Modern Styling:** Styled entirely with the newly released Tailwind CSS v4 using glassmorphism (backdrop-blur) UI techniques.
- **Responsive Architecture:** Fully mobile-optimized, seamless navigation across Home, Projects, Skills, and About pages using React Router.

## 🛠️ Tech Stack
- **Frontend Framework:** React 18 (Vite)
- **Routing:** React Router v6
- **Styling:** Tailwind CSS v4
- **Animation Engine:** GSAP (GreenSock) + `@gsap/react`
- **Icons:** Lucide React & React Icons
- **Deployment:** Vercel (Recommended)
